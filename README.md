# Profile Card 📱

Una tarjeta de presentación digital e interactiva diseñada para resumir mi perfil profesional y agrupar mis enlaces más importantes en un solo lugar. 

Este proyecto fue construido desde cero con el objetivo de consolidar mis conocimientos fundamentales de maquetación y diseño adaptable.

## 🚀 Demo En Vivo
Puedes ver el proyecto funcionando en tiempo real a través de GitHub Pages en el siguiente enlace:
👉 [Ver demo en vivo](https://jeandevel.github.io/profile-card/)

---

## 🛠️ Tecnologías Utilizadas

*   **HTML5:** Estructura semántica y organización del contenido.
*   **CSS3:** Estilos personalizados, diseño adaptable y distribución de componentes mediante Flexbox.

---

## 💡 Aprendizajes Clave

Durante las **2.5 horas** de desarrollo de este proyecto, logré poner en práctica y perfeccionar los siguientes conceptos frontend:

1.  **Centrado Absoluto:** Dominio de alineación de elementos en el viewport tanto vertical como horizontalmente.
2.  **Manejo de Flexbox:** Uso de propiedades como `display: flex`, `justify-content` y `gap` para ordenar los botones de manera simétrica.
3.  **Estilos e Interfaz Limpia:** Aplicación de una paleta de colores minimalista, bordes redondeados (`border-radius`) e imágenes en formato circular.
